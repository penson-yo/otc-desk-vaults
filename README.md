# OTC Desk Vaults

Read-only inspector for [OTC Desks](https://otcdesks.cash) NFT vaults on Solana.

This app cannot move funds. It talks to a public RPC, never holds keys, and has no transfer, swap, approve, or mint instructions. Paste a wallet or connect read-only.

Public watch-only defaults: Seeker desks, Fomo `$OTC`.
